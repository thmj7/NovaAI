# NovaAI – AI Chatbot

A modern, responsive AI chatbot interface built using **HTML, CSS, and JavaScript**. NovaAI provides a ChatGPT-inspired user experience with features like conversation history, dark mode, voice input, emoji support, file attachments, local memory, and an intelligent rule-based NLP engine capable of answering questions, solving math problems, generating stories, quizzes, jokes, and more.

---

## ✨ Features

* 💬 Modern AI chatbot interface
* 🌙 Light & Dark mode
* 🎙️ Voice input (Speech Recognition API)
* 📎 File attachment support
* 😊 Emoji picker
* 💾 Local conversation history using Local Storage
* 🧠 Local memory (remembers user name)
* ➗ Natural language calculator
* 📖 Story generation
* 🧩 Riddles and quizzes
* 😂 Joke generator
* 📚 Educational assistance (HTML, CSS, JavaScript, AI, Agile, Scrum, etc.)
* 📱 Fully responsive design

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* Local Storage API
* Web Speech API

## 🚀 Getting Started

1. Clone this repository:

```bash
git clone https://github.com/your-username/novaai-chatbot.git
```

2. Open the project folder.

3. Run `index.html` in your browser.

No installation or additional dependencies are required.
